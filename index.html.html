Part A · 01

Linear equations

A linear equation has the variable to the power 1 only. Solving means finding the value that makes the left side equal the right side.

Think of an equation as a balanced scale. Any operation applied to one side must be applied to the other, so the scale stays level. The aim is to leave the variable alone on one side.

Method
  1. Remove brackets (distributive law).
  2. Move variable terms to one side and constants to the other (use inverse operations).
  3. Collect like terms.
  4. Divide by the coefficient of the variable.
  5. Check by substituting into the original equation.
Example 1.1One-step inverse operations

Solve \(3x + 5 = 20\).

$$\begin{aligned} 3x + 5 &= 20 \\ 3x &= 15 &&\text{subtract 5 both sides}\\ x &= 5 &&\text{divide both sides by 3}\end{aligned}$$

Check: \(3(5)+5 = 20\). \(x = 5\)

Example 1.2Brackets on both sides

Solve \(3(x - 2) + 5 = 2x + 7\).

$$\begin{aligned} 3x - 6 + 5 &= 2x + 7 &&\text{expand}\\ 3x - 1 &= 2x + 7 &&\text{collect constants}\\ 3x - 2x &= 7 + 1 \\ x &= 8\end{aligned}$$ \(x = 8\)
Example 1.3Word problem

The sum of three consecutive integers is 84. Find the integers.

Let the integers be \(n,\; n+1,\; n+2\).

$$\begin{aligned} n + (n+1) + (n+2) &= 84\\ 3n + 3 &= 84\\ 3n &= 81\\ n &= 27\end{aligned}$$ 27, 28 and 29
Example 1.4Literal equation (change the subject)

Make \(x\) the subject of \(ax + b = c\).

$$\begin{aligned} ax &= c - b\\ x &= \frac{c-b}{a}, \quad a \ne 0\end{aligned}$$

Same steps as with numbers — the letters simply stay as letters.

Part A · 02

Equations with fractions

Fractions are removed by multiplying every term on both sides by the lowest common denominator (LCD).

STEP 1Factorise denominators and state restrictions (denominator ≠ 0).
→
STEP 2Find the LCD of all denominators.
→
STEP 3Multiply every term by the LCD; fractions cancel.
→
STEP 4Solve, then reject any answer that breaks a restriction.
Example 2.1Numerical denominators

Solve \(\dfrac{x}{2} + \dfrac{x}{3} = 10\).

$$\begin{aligned} 6\cdot\frac{x}{2} + 6\cdot\frac{x}{3} &= 6\cdot 10 \\ 3x + 2x &= 60\\ 5x &= 60\\ x &= 12\end{aligned}$$ \(x = 12\)
Example 2.2Binomial numerators — watch the minus sign

Solve \(\dfrac{x+1}{3} - \dfrac{x-2}{4} = 1\).

LCD = 12. Keep the numerators in brackets so the negative applies to the whole numerator.

$$\begin{aligned} 4(x+1) - 3(x-2) &= 12\\ 4x + 4 - 3x + 6 &= 12\\ x + 10 &= 12\\ x &= 2\end{aligned}$$ \(x = 2\)
Example 2.3Variable in the denominator

Solve \(\dfrac{2}{x-1} + 1 = \dfrac{3}{x-1}\).

Restriction: \(x \ne 1\). Multiply every term by \((x-1)\):

$$\begin{aligned} 2 + (x - 1) &= 3\\ x + 1 &= 3\\ x &= 2\end{aligned}$$

2 does not break the restriction. \(x = 2\)

Example 2.4Rejected solution

Solve \(\dfrac{x}{x-3} = \dfrac{3}{x-3} + 2\).

Restriction: \(x \ne 3\). Multiply by \((x-3)\):

$$\begin{aligned} x &= 3 + 2(x-3)\\ x &= 2x - 3\\ x &= 3\end{aligned}$$

But \(x = 3\) makes the denominator zero, so it is rejected. No solution

Example 2.5Factorise first

Solve \(\dfrac{1}{x-2} + \dfrac{2}{x+2} = \dfrac{6}{x^2-4}\).

\(x^2 - 4 = (x-2)(x+2)\), so the LCD is \((x-2)(x+2)\). Restrictions: \(x \ne 2,\; x \ne -2\).

$$\begin{aligned} (x+2) + 2(x-2) &= 6\\ 3x - 2 &= 6\\ x &= \frac{8}{3}\end{aligned}$$ \(x = \tfrac{8}{3}\)
Part A · 03

Exponential equations

The variable sits in the exponent. Strategy: write both sides as powers of the same base, then equate the exponents.

LawStatementExample
Product\(a^m \cdot a^n = a^{m+n}\)\(2^3\cdot 2^4 = 2^7\)
Quotient\(\dfrac{a^m}{a^n} = a^{m-n}\)\(\dfrac{5^6}{5^2} = 5^4\)
Power of a power\((a^m)^n = a^{mn}\)\((3^2)^x = 3^{2x}\)
Power of a product\((ab)^n = a^n b^n\)\((2x)^3 = 8x^3\)
Zero exponent\(a^0 = 1,\; a \ne 0\)\(7^0 = 1\)
Negative exponent\(a^{-n} = \dfrac{1}{a^n}\)\(\dfrac{1}{8} = 2^{-3}\)
Rational exponent\(a^{\frac{m}{n}} = \sqrt[n]{a^m}\)\(8^{\frac{2}{3}} = 4\)
Three types to recognise
  1. Same base: write both sides with the same prime base, equate exponents.
  2. Common factor: terms like \(3^{x+2} - 3^x\) — take out the smallest power \(3^x\).
  3. Quadratic in disguise: \(4^x - 5\cdot2^x + 4 = 0\) — let \(k = 2^x\).
Example 3.1Same base

Solve \(2^{x+1} = 32\).

$$\begin{aligned} 2^{x+1} &= 2^5\\ x + 1 &= 5\\ x &= 4\end{aligned}$$ \(x = 4\)
Example 3.2Different bases, same prime

Solve \(9^{x} = 27^{x-1}\).

$$\begin{aligned} (3^2)^x &= (3^3)^{x-1}\\ 3^{2x} &= 3^{3x-3}\\ 2x &= 3x - 3\\ x &= 3\end{aligned}$$ \(x = 3\)
Example 3.3Negative exponent

Solve \(5^{x} = \dfrac{1}{125}\).

$$5^x = \frac{1}{5^3} = 5^{-3} \quad\Rightarrow\quad x = -3$$ \(x = -3\)
Example 3.4Common factor

Solve \(3^{x+2} - 3^{x} = 72\).

$$\begin{aligned} 3^x\cdot 3^2 - 3^x &= 72\\ 3^x(9 - 1) &= 72\\ 3^x &= 9 = 3^2\\ x &= 2\end{aligned}$$ \(x = 2\)
Example 3.5Quadratic in disguise

Solve \(4^{x} - 5\cdot 2^{x} + 4 = 0\).

\(4^x = (2^x)^2\). Let \(k = 2^x\):

$$\begin{aligned} k^2 - 5k + 4 &= 0\\ (k-1)(k-4) &= 0\\ k = 1 \quad&\text{or}\quad k = 4\\ 2^x = 2^0 \quad&\text{or}\quad 2^x = 2^2\end{aligned}$$ \(x = 0\) or \(x = 2\)
Example 3.6Variable in the base

Solve \(x^{\frac{3}{2}} = 8\).

Raise both sides to the reciprocal exponent \(\tfrac{2}{3}\):

$$x = 8^{\frac{2}{3}} = \left(\sqrt[3]{8}\right)^2 = 2^2 = 4$$ \(x = 4\)
Part A · 04

Linear inequalities

Solved exactly like equations, with one extra rule: multiplying or dividing by a negative number reverses the inequality sign.

Why the sign flips

\(2 < 5\) is true. Multiply both sides by \(-1\): \(-2\) and \(-5\). On the number line \(-2\) is to the right of \(-5\), so \(-2 > -5\). Multiplying by a negative mirrors the number line, which reverses order.

InequalityNumber lineInterval notation
\(x > a\)open dot at \(a\), arrow right\((a;\ \infty)\)
\(x \ge a\)closed dot at \(a\), arrow right\([a;\ \infty)\)
\(x < a\)open dot at \(a\), arrow left\((-\infty;\ a)\)
\(a < x \le b\)open at \(a\), closed at \(b\), segment between\((a;\ b]\)
Example 4.1Basic

Solve \(2x - 5 > 7\) and write the answer in interval notation.

$$\begin{aligned} 2x &> 12\\ x &> 6\end{aligned}$$ \(x > 6\), i.e. \((6;\ \infty)\)
Example 4.2Dividing by a negative

Solve \(-3x + 4 \le 13\).

$$\begin{aligned} -3x &\le 9\\ x &\ge -3 &&\text{divide by } -3\text{: sign flips}\end{aligned}$$ \(x \ge -3\) — see the top number line above.
Example 4.3Double inequality

Solve \(-1 < 2x + 3 \le 7\).

Apply each step to all three parts.

$$\begin{aligned} -4 &< 2x \le 4\\ -2 &< x \le 2\end{aligned}$$ \(x \in (-2;\ 2]\)
Example 4.4Fractions

Solve \(\dfrac{x-1}{2} - \dfrac{x+3}{3} \ge 1\).

Multiply by LCD 6 (positive, so no flip):

$$\begin{aligned} 3(x-1) - 2(x+3) &\ge 6\\ 3x - 3 - 2x - 6 &\ge 6\\ x - 9 &\ge 6\\ x &\ge 15\end{aligned}$$ \(x \ge 15\)
Example 4.5Integer solutions

List the integers that satisfy \(-2 < x \le 2\).

\(-2\) is excluded (open), 2 is included (closed).

\(-1,\ 0,\ 1,\ 2\)
Part A · 05

Simultaneous equations

Two equations, two unknowns. The solution is the pair \((x;\ y)\) that satisfies both at the same time — graphically, the point where the lines intersect.

MethodWhen to useIdea
EliminationCoefficients line up or are easy to matchAdd or subtract the equations so one variable cancels.
SubstitutionOne variable is already isolated, or one equation is non-linearMake one variable the subject, substitute into the other equation.
GraphicalAsked to interpret, or to checkDraw both graphs; read the intersection.
Example 5.1Elimination

Solve \(2x + y = 7\) and \(x - y = 2\).

Add the equations — \(y\) cancels:

$$\begin{aligned} 3x &= 9 \Rightarrow x = 3\\ 3 - y &= 2 \Rightarrow y = 1\end{aligned}$$ \((3;\ 1)\)
Example 5.2Substitution

Solve \(y = 2x - 1\) and \(3x + 2y = 19\).

$$\begin{aligned} 3x + 2(2x - 1) &= 19\\ 7x - 2 &= 19\\ x &= 3\\ y &= 2(3) - 1 = 5\end{aligned}$$ \((3;\ 5)\)
Example 5.3Elimination with multipliers

Solve \(3x + 2y = 12\) and \(5x - 3y = 1\).

Multiply the first equation by 3 and the second by 2 so the \(y\)-terms are \(+6y\) and \(-6y\):

$$\begin{aligned} 9x + 6y &= 36\\ 10x - 6y &= 2\\ \hline 19x &= 38 \Rightarrow x = 2\\ 3(2) + 2y &= 12 \Rightarrow y = 3\end{aligned}$$ \((2;\ 3)\)
Example 5.4Equations containing fractions

Solve \(\dfrac{x}{2} + \dfrac{y}{3} = 4\) and \(x - y = 3\).

Clear fractions (× 6): \(3x + 2y = 24\). From the second equation, \(x = y + 3\).

$$\begin{aligned} 3(y+3) + 2y &= 24\\ 5y + 9 &= 24\\ y &= 3,\quad x = 6\end{aligned}$$ \((6;\ 3)\)
Example 5.5One linear, one quadratic

Solve \(y = x + 1\) and \(y = x^2 - 1\).

$$\begin{aligned} x^2 - 1 &= x + 1\\ x^2 - x - 2 &= 0\\ (x-2)(x+1) &= 0\\ x = 2 \Rightarrow y = 3 \quad&\text{or}\quad x = -1 \Rightarrow y = 0\end{aligned}$$

A line can cut a parabola in two points, so there are two solution pairs.

\((2;\ 3)\) and \((-1;\ 0)\)
Example 5.6Word problem

Adult tickets cost R50 and child tickets R30. Twelve tickets cost R480 in total. How many of each were bought?

$$\begin{aligned} a + c &= 12\\ 50a + 30c &= 480\\ 50a + 30(12 - a) &= 480\\ 20a &= 120 \Rightarrow a = 6,\ c = 6\end{aligned}$$ 6 adult, 6 child
Part B · 06

Theoretical and relative frequency probability

Probability measures how likely an event is, on a scale from 0 (impossible) to 1 (certain).

TermMeaningDie example
ExperimentA repeatable action with uncertain resultRolling a die
OutcomeOne possible resultRolling a 4
Sample space \(S\)Set of all outcomes\(S = \{1,2,3,4,5,6\},\ n(S) = 6\)
Event \(E\)A subset of the sample spaceEven: \(E = \{2,4,6\}\)
Two kinds of probability

Theoretical (outcomes equally likely): $$P(E) = \frac{n(E)}{n(S)} = \frac{\text{number of favourable outcomes}}{\text{total number of outcomes}}$$

Relative frequency (from an experiment): $$\text{Relative frequency} = \frac{\text{number of times the event occurred}}{\text{total number of trials}}$$

As the number of trials grows, relative frequency settles towards the theoretical probability (law of large numbers).

Example 6.1Theoretical probability

A fair die is rolled. Find \(P(\text{prime number})\).

Primes on a die: \(\{2, 3, 5\}\), so \(n(E) = 3\).

$$P(\text{prime}) = \frac{3}{6} = \frac{1}{2}$$

1 is not prime.

Example 6.2Two dice

Two dice are rolled. Find the probability that the sum is 7.

Favourable: (1;6), (2;5), (3;4), (4;3), (5;2), (6;1) — 6 outcomes. Use the grid above to see them on a diagonal.

$$P(\text{sum} = 7) = \frac{6}{36} = \frac{1}{6}$$
Example 6.3Relative frequency from a table

A spinner with four equal sectors is spun 80 times.

ColourRedBlueGreenYellow
Frequency26182016

(a) Find the relative frequency of red. (b) Compare it with the theoretical probability. (c) Using relative frequency, predict the number of greens in 200 spins.

(a) \(\dfrac{26}{80} = 0{,}325\)

(b) Theoretical \(P(\text{red}) = \tfrac{1}{4} = 0{,}25\). The experimental value is higher; with only 80 spins this is normal variation. More spins would bring it closer to 0,25.

(c) \(\dfrac{20}{80} \times 200 = 50\) greens.

Venn diagrams

A Venn diagram shows how events overlap. The rectangle is the sample space \(S\); each circle is an event.

NotationRead asMeaning
\(A \cup B\)A union BA or B (or both)
\(A \cap B\)A intersection BA and B
\(A'\)A complementnot A
\(n(A)\)number in Acount of outcomes in A

Interactive: shade a region

40 learners: 22 play soccer (A), 18 play netball (B), 7 play both. Click an expression to shade it and see its count and probability.

Example 7.1Two-set Venn diagram

Using the soccer–netball data above, find: (a) \(P(\text{soccer only})\) (b) \(P(A \cup B)\) (c) \(P(\text{neither})\) (d) \(P(\text{exactly one sport})\).

(a) \(\dfrac{15}{40} = \dfrac{3}{8}\)

(b) \(\dfrac{15 + 7 + 11}{40} = \dfrac{33}{40}\), or by the addition rule \(\dfrac{22}{40} + \dfrac{18}{40} - \dfrac{7}{40} = \dfrac{33}{40}\)

(c) \(\dfrac{7}{40}\)

(d) \(\dfrac{15 + 11}{40} = \dfrac{26}{40} = \dfrac{13}{20}\)

Example 7.2Find an unknown

In a class of 30, 18 like tea, 15 like coffee and 5 like neither. How many like both?

Let \(x\) = number who like both. Then tea only \(= 18 - x\), coffee only \(= 15 - x\).

$$\begin{aligned} (18 - x) + x + (15 - x) + 5 &= 30\\ 38 - x &= 30\\ x &= 8\end{aligned}$$ 8 like both
Example 7.3Three-set Venn diagram

60 learners were surveyed. 35 take Maths (M), 21 Physics (P), 22 Life Sciences (L). 10 take M and P, 9 take M and L, 7 take P and L, and 4 take all three. Draw the Venn diagram and find (a) the number taking none, (b) \(P(\text{exactly one subject})\), (c) \(P(\text{at least two subjects})\).

Always fill from the centre outward:

  1. All three: 4
  2. M and P only: 10 − 4 = 6; M and L only: 9 − 4 = 5; P and L only: 7 − 4 = 3
  3. M only: 35 − 6 − 5 − 4 = 20; P only: 21 − 6 − 3 − 4 = 8; L only: 22 − 5 − 3 − 4 = 10
  4. None: 60 − (20 + 8 + 10 + 6 + 5 + 3 + 4) = 4

(a) 4 take none

(b) \(\dfrac{20 + 8 + 10}{60} = \dfrac{38}{60} = \dfrac{19}{30}\)

(c) \(\dfrac{6 + 5 + 3 + 4}{60} = \dfrac{18}{60} = \dfrac{3}{10}\)

Part B · 08

Rules of probability

Complement, union and intersection are connected by a small set of rules. Learn when each one applies.

The complement

An event either happens or it does not, so \(A\) and \(A'\) together fill the sample space:

$$P(A') = 1 - P(A)$$

Use it for "at least one" and "not" questions — it is often quicker to find the probability of the opposite.

Union and intersection: the addition rule

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

Adding \(P(A)\) and \(P(B)\) counts the overlap twice, so it is subtracted once.

Special relationships between events

RelationshipMeaningTest / rule
Mutually exclusiveCannot occur together\(P(A \cap B) = 0\); \(P(A\cup B) = P(A) + P(B)\)
ExhaustiveTogether they cover all outcomes\(A \cup B = S\); \(P(A \cup B) = 1\)
ComplementaryMutually exclusive and exhaustive\(P(A) + P(B) = 1\)
IndependentOne does not affect the other\(P(A \cap B) = P(A)\times P(B)\)

Mutually exclusive is not the same as independent. If \(A\) and \(B\) are mutually exclusive (with non-zero probabilities), knowing \(A\) happened tells you \(B\) did not — so they are dependent.

Tree diagrams for successive events

Example 8.1Addition rule, complement, independence

\(P(A) = 0{,}45\), \(P(B) = 0{,}3\) and \(P(A \cup B) = 0{,}6\). Find (a) \(P(A \cap B)\) (b) \(P(A')\) (c) \(P(A' \cap B')\) (d) \(P(A \text{ only})\) (e) Are \(A\) and \(B\) independent?

(a) \(0{,}6 = 0{,}45 + 0{,}3 - P(A\cap B) \Rightarrow P(A \cap B) = 0{,}15\)

(b) \(P(A') = 1 - 0{,}45 = 0{,}55\)

(c) \(A' \cap B'\) is "neither", which equals \((A \cup B)'\): \(1 - 0{,}6 = 0{,}4\)

(d) \(P(A) - P(A \cap B) = 0{,}45 - 0{,}15 = 0{,}30\)

(e) \(P(A)\times P(B) = 0{,}135 \ne 0{,}15\). Not independent

Example 8.2Mutually exclusive

\(A\) and \(B\) are mutually exclusive with \(P(A) = 0{,}2\) and \(P(B) = 0{,}5\). Find \(P(A \cup B)\) and \(P(A' \cap B')\).

$$P(A\cup B) = 0{,}2 + 0{,}5 = 0{,}7 \qquad P(A'\cap B') = 1 - 0{,}7 = 0{,}3$$
Example 8.3Overlapping events in a deck

A card is drawn from a standard 52-card deck. Find \(P(\text{king or heart})\).

4 kings, 13 hearts, 1 king of hearts (the overlap).

$$P = \frac{4}{52} + \frac{13}{52} - \frac{1}{52} = \frac{16}{52} = \frac{4}{13}$$
Example 8.4Tree diagram

Using the bag in the tree diagram (3 red, 2 blue, with replacement), find (a) \(P(\text{same colour})\) (b) \(P(\text{at least one blue})\). (c) Find \(P(RR)\) if the first ball is not replaced.

(a) \(P(RR) + P(BB) = \dfrac{9}{25} + \dfrac{4}{25} = \dfrac{13}{25}\)

(b) Complement of "no blue": \(1 - P(RR) = 1 - \dfrac{9}{25} = \dfrac{16}{25}\)

(c) Without replacement one red is gone: \(\dfrac{3}{5}\times\dfrac{2}{4} = \dfrac{6}{20} = \dfrac{3}{10}\)

Example 8.5"At least one" via the complement

A die is rolled twice. Find \(P(\text{at least one six})\).

$$P(\text{at least one 6}) = 1 - P(\text{no 6}) = 1 - \frac{5}{6}\times\frac{5}{6} = 1 - \frac{25}{36} = \frac{11}{36}$$

Mixed practice

Exam-style questions across the full scope. Use the board to work them out, then check.

Q1Linear · 2 marks

Solve \(5x - 3 = 2(x + 6)\).

$$5x - 3 = 2x + 12 \Rightarrow 3x = 15 \Rightarrow x = 5$$
Q2Fractions · 3 marks

Solve \(\dfrac{2x-1}{5} = \dfrac{x+4}{3}\).

$$3(2x-1) = 5(x+4) \Rightarrow 6x - 3 = 5x + 20 \Rightarrow x = 23$$
Q3Exponential · 3 marks

Solve \(8^{x-1} = 4^{x}\).

$$2^{3x-3} = 2^{2x} \Rightarrow 3x - 3 = 2x \Rightarrow x = 3$$
Q4Exponential · 3 marks

Solve \(2^{x} + 2^{x+3} = 72\).

$$2^x(1 + 8) = 72 \Rightarrow 2^x = 8 \Rightarrow x = 3$$
Q5Inequality · 3 marks

Solve \(4 - 3x < 19\) and represent the solution on a number line.

$$-3x < 15 \Rightarrow x > -5$$

Open dot at −5, arrow to the right.

Q6Simultaneous · 4 marks

Solve \(4x + 3y = 18\) and \(x - y = 1\).

$$x = y + 1 \Rightarrow 4(y+1) + 3y = 18 \Rightarrow 7y = 14 \Rightarrow y = 2,\ x = 3$$\((3;\ 2)\)
Q7Mutually exclusive · 2 marks

\(P(A) = 0{,}6\), \(P(B) = 0{,}25\), \(A\) and \(B\) mutually exclusive. Find \(P(A\cup B)\) and \(P\big((A \cup B)'\big)\).

$$P(A \cup B) = 0{,}85 \qquad P\big((A\cup B)'\big) = 0{,}15$$
Q8Independence · 3 marks

\(P(A) = 0{,}5\), \(P(B) = 0{,}4\), \(P(A \cap B) = 0{,}2\). Are \(A\) and \(B\) independent? Find \(P(A \cup B)\).

$$0{,}5 \times 0{,}4 = 0{,}2 = P(A\cap B) \Rightarrow \text{independent}$$$$P(A\cup B) = 0{,}5 + 0{,}4 - 0{,}2 = 0{,}7$$
Q9Venn · 4 marks

Of 50 people, 30 own a cat, 25 own a dog and 8 own neither. Find the probability that a person chosen at random owns both.

$$n(C\cup D) = 50 - 8 = 42 = 30 + 25 - x \Rightarrow x = 13$$$$P(\text{both}) = \frac{13}{50}$$
Q10Complement · 2 marks

A coin is tossed three times. Find \(P(\text{at least one head})\).

$$1 - P(TTT) = 1 - \left(\tfrac{1}{2}\right)^3 = \frac{7}{8}$$
